# BharatMoney Finance OS v6

A resume-ready Indian personal finance dashboard built with **React + HTML/JSX + CSS + JavaScript only**.

## Included
- Login / demo authentication using browser localStorage
- Indian ₹ / INR finance UI
- Optional monthly salary income
- Dashboard command center
- Financial Health Score
- Spending Radar
- Smart Insight card
- 30-day balance forecast
- Goals and savings runway
- Transactions search and quick-add modal
- Analytics and category spending chart
- Financial calendar
- Profile/settings page
- Responsive mobile layout
- Indian multi-color visual system: saffron, emerald, royal blue, gold + deep navy
- Animated bars, score ring, hover states and glass panels
- No backend, database, JWT, API server or `.env` required

## Run
```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Build
```bash
npm run build
```
